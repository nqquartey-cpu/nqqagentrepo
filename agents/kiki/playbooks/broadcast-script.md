# Playbook: AMPU Broadcast Script (2 hours)

**Input:** show rundown (segments, guests, linked source articles), date.
**Output:** `output/kiki/YYYY-MM-DD/ampu-script-YYYY-MM-DD.md`

## Steps
1. Read every linked article. Pull facts only from them (or a fresh search, cited).
2. Build the clock: cold open → segments in rundown order → breaks → close.
3. Per segment: host intro (why it matters), key facts, guest intro with exact name + affiliation, 3–5 questions, transition.
4. Close with a reflection and the signature line: *When we come forward — we are forward.*
5. Mark any unverified fact `[VERIFY: …]`. List sources at the bottom.

## Quality check
- Every guest name/affiliation matches the rundown or brand-voice.md
- No invented quotes
- Timing roughly fills two hours with breaks marked
- Voice: warm, civic, culturally fluent
