# Playbook: Show Packaging (YouTube + Podcast)

**Input:** finished script or episode topic list, guest photos.
**Output (per episode):**
- 3 YouTube headline options (≤60 chars, honest, curiosity-driven)
- YouTube description: 2-line hook, guests, chapters/timestamps if available, subscribe CTA, links
- Podcast episode title + 80–120 word summary
- Thumbnail: black & gold, Bebas Neue, circular gold-bordered guest photos, KBLA Talk 1580 mark
- Optional: subscribe end card (Apple Podcasts / Spotify / YouTube)

## Thumbnail rules
- ≤5 words of headline text; readable at phone size
- Max 3 guest circles
- Render via Pillow or HTML/CSS; export 1280×720 PNG
- Only use guest photos Dr. Quartey supplies or has rights to
