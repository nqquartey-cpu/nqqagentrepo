# AMPU YouTube Thumbnail Template (v2, Nov 2026)
1280×720 · black & gold · Bebas Neue + Oswald · real photo only (Thumbnail Guardian rule).

**Per episode, edit `ampu-thumb.html`:**
- `--date` / `--time` in `:root`
- the four guest blocks: photo (`g_<name>.png`, square, face centered) + name
- Swap `host_cut.png` for another real cutout if you want a different pose

**Render:** `node render.js out.png` (Playwright) → export JPG under 2 MB for YouTube.
Concept: host's open palm "presents" today's conversation; gold rim light + rays on his real Hollywood rooftop.
